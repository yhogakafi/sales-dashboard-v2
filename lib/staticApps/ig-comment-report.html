Laporan Komentar Instagram

Upload file HTML hasil unduhan "Post comments" dari Instagram (menu Unduh Informasi Anda / Download Your Information). Tool ini merapikan seluruh komentar jadi tabel yang bisa dicari, difilter, dan diekspor ke Excel — siap dikirim sebagai laporan.

Seret file .html hasil ekspor "Post comments" Instagram ke sini, atau klik untuk memilih

Contoh nama file: post_comments_1.html — dari paket "Download Your Information" (format HTML)

Yang dibaca dari file: setiap entri komentar (akun yang dikomentari / "Media Owner", isi komentar, dan waktu). Komentar berupa GIF/stiker tanpa teks tetap dicatat dan ditandai sebagai GIF/Stiker.
  1. Buka permintaan data Anda di Instagram → Unduh Informasi Anda, pilih format HTML.
  2. Cari file bernama post_comments_*.html di dalam hasil unduhan.
  3. Upload file itu di sini — semuanya diproses langsung di browser, tidak dikirim ke server manapun.
